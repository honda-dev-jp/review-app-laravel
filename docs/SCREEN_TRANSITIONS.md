# 画面遷移

## このドキュメントの目的

このドキュメントでは、映画レビューアプリ Laravel移植版の画面遷移を整理する。

初期移植フェーズでは、既存スクラッチ版の最低限機能をLaravelへ移植するため、ゲスト・会員・共通画面を中心に整理する。

管理者画面はMVP1では対象外とし、MVP2で管理者画面モック、登録済み作品一覧、TMDB検索からの1作品登録に必要な導線を段階的に検討する。

## 画面区分

| 区分 | 概要 |
|---|---|
| 共通画面 | ゲスト・会員・管理者が閲覧できる公開画面 |
| ゲスト画面 | ログインしていないユーザーが利用する画面 |
| 会員画面 | ログイン済みユーザーが利用する画面 |
| 管理者画面 | 作品情報を管理する画面。初期移植フェーズでは対象外 |

## 主要な実装済み画面一覧

### 共通画面

| 画面 | 概要 | 認証 |
|---|---|---|
| 作品一覧画面 | 登録済み作品を一覧表示する | 不要 |
| 作品詳細画面 | 作品詳細、レビュー、レビュー返信、投稿者アイコン、星評価を表示する | 不要 |

### ゲスト画面

| 画面 | 概要 | 認証 |
|---|---|---|
| 会員登録画面 | 新規会員登録を行う | 未ログイン限定（`guest`） |
| ログイン画面 | 既存会員がログインする | 未ログイン限定（`guest`） |
| パスワードリセット申請画面 | 登録済みメールアドレスへ再設定URLの送信を申請する | 未ログイン限定（`guest`） |
| パスワード再設定画面 | メール内の再設定URLから新しいパスワードを設定する | 未ログイン限定（`guest`） |

### 会員画面

| 画面 | 概要 | 認証 |
|---|---|---|
| アカウント画面 | ユーザー名・プロフィール情報・ユーザーアイコン・パスワードを更新し、確認モーダルから会員退会を行う | 必要 |
| 本人のレビュー一覧画面 | 自分が投稿したレビューとユーザーアイコンを一覧表示する | 必要 |
| メール認証案内画面 | 未認証ユーザーに認証メール確認と再送導線を表示する | 必要 |

### 管理者画面

| 画面 | 概要 | 認証 | メール認証 | 認可 |
|---|---|---|---|---|
| 管理画面ダッシュボード | 管理者画面の基本構成と操作導線を表示する | 必要 | 不要 | 管理者のみ |

### ユーザーアイコンの扱い

ユーザーアイコンの登録・差し替えは既存のアカウント画面の編集フォームへ統合し、現在画像とファイル選択後の保存前プレビューを表示する。新しい画面や画面遷移は追加せず、画像単独削除と「No Imageへ戻す」機能は設けない。

アイコンはPC・モバイルナビゲーション、アカウント画面、作品詳細のレビュー投稿者・レビュー返信投稿者、本人レビュー一覧に表示する。退会済み投稿者は匿名名とNo Image画像で表示し、退会確認モーダルは表示対象外とする。正方形の円形領域へ中央基準で表示し、長いユーザー名の横でも縮小させない。

## 共通ナビゲーション

共通ヘッダーには、ログイン状態に応じたナビゲーションを表示する。

### ゲスト表示

- 作品一覧
- ログイン
- 会員登録

### 会員表示

- 作品一覧
- アカウント
- 本人のレビュー一覧
- ログアウト

会員表示のナビゲーションには、ログインユーザーのアイコンも表示する。

パスワードリセットは共通ナビゲーションに表示せず、ログイン画面内の「パスワードを忘れた場合」リンクのみを導線とする。

退会は危険操作のため、共通ナビゲーションには直接表示しない。

退会導線はアカウント画面配下に配置する。

### レスポンシブ対応

PC表示ではヘッダーにナビゲーションを表示する。

スマホ表示ではハンバーガーメニュー内にナビゲーションを表示する。

ナビゲーションの表示切り替えは Blade の `@auth` / `@guest` を使用する。

ログイン必須ページへのアクセス制御は `auth` ミドルウェアで行う。レビュー・評価投稿とレビュー返信投稿は、メール認証済みユーザーに限定するため `verified` ミドルウェアも使用する。管理画面ダッシュボードはメール認証を要求せず、管理者だけが利用できる。

## 共通画面の遷移

```text
作品一覧画面
  └─ 作品リンククリック
      ↓
      作品詳細画面
        ├─ レビュー表示
        ├─ レビュー返信表示
        └─ 星評価表示
```

## ゲストの画面遷移

```text
共通ナビゲーション
  ├─ 作品一覧画面
  ├─ ログイン画面
  └─ 会員登録画面

作品一覧画面
  └─ 作品リンククリック
      ↓
      作品詳細画面
        ├─ レビュー表示
        ├─ レビュー返信表示
        └─ 星評価表示

会員登録画面
  ↓
登録完了後
  ↓
作品一覧画面

ログイン画面
  └─ パスワードを忘れた場合
      ↓
パスワードリセット申請画面
  ↓ リセットメール送信
  ↓ メール内の再設定URL
パスワード再設定画面
  ↓ 再設定完了
ログイン画面
```

レビュー・評価投稿やレビュー返信投稿などの会員操作は、会員の画面遷移に整理する。

### 認証画面UIの扱い

会員登録画面、ログイン画面、パスワードリセット申請画面、パスワード再設定画面は、Laravel Breezeの認証機能を利用する。

認証処理はBreeze標準を維持している。

会員登録画面・ログイン画面は、Issue #16で映画レビューアプリ向けに調整済みである。

パスワードリセット申請画面・パスワード再設定画面も、共通のゲストレイアウトを通じて同じロゴ・カードUIを使用する。

会員登録後は未認証状態でログインし、作品一覧画面へ遷移する。登録直後に `/verify-email` へ自動遷移しない。

ログイン前に認証必須URLへアクセスしていた場合は、ログイン成功後にそのURLへ戻る。元のURLがない通常ログイン時だけ、一般ユーザーは作品一覧画面、管理者は管理画面ダッシュボードを遷移先のfallbackとする。

## ログイン後の画面遷移

```text
ログイン画面
  ↓
ログイン成功
  ├─ ログイン前にアクセスしていた認証必須URLあり
  │   ↓
  │   元のURL
  └─ 元のURLなし
      ├─ 一般ユーザー → 作品一覧画面
      └─ 管理者 → 管理画面ダッシュボード

作品一覧画面
  └─ 作品リンククリック
      ↓
      作品詳細画面
        ├─ レビュー・評価投稿
        └─ レビュー返信投稿

共通ナビゲーション
  ├─ アカウント画面
  │   └─ 会員退会確認モーダル
  ├─ 本人のレビュー一覧画面
  │   └─ レビュー削除
  └─ ログアウト
```

元のURLがない通常ログインでは、一般ユーザーは作品一覧画面、管理者は管理画面ダッシュボードへ遷移する。ログイン前に認証必須URLへアクセスしていた場合は、そのURLへの遷移を優先する。

レビュー削除は、本人のレビュー一覧画面からのみ実行できるものとする。

作品詳細画面ではレビュー削除導線を表示しない。

### メール未認証ユーザーの遷移

```text
作品詳細画面
  ├─ レビュー・評価投稿を送信
  │   ↓
  │   メール認証案内画面（/verify-email）
  └─ レビュー返信投稿を送信
      ↓
      メール認証案内画面（/verify-email）

メール認証案内画面
  ├─ 認証メール再送
  │   ↓
  │   メール認証案内画面
  └─ メール内の認証URL
      ↓
      認証完了
        ├─ intended URLがある場合
        │   ↓
        │   認証必須操作の開始元画面
        │   （例：作品詳細画面）
        └─ intended URLがない場合
            ↓
            作品一覧画面

アカウント画面
  └─ メールアドレス未確認の場合
      └─ 確認用メールを再送
          ↓
          アカウント画面
```

認証済みユーザーが `/verify-email` へアクセスした場合は、作品一覧画面へリダイレクトする。

## 認証が必要な画面・操作

| 画面・操作 | 認証 | メール認証 | 認可 |
|---|---|---|---|
| メール認証案内画面 | 必要 | 不要 | ログインユーザー本人 |
| 認証メール再送 | 必要 | 不要 | ログインユーザー本人 |
| レビュー・評価投稿 | 必要 | 必要 | 会員のみ |
| レビュー削除 | 必要 | 不要 | 自分のレビューのみ |
| レビュー返信投稿 | 必要 | 必要 | 会員のみ |
| アカウント情報の編集 | 必要 | 不要 | 自分のプロフィールのみ |
| 本人のレビュー一覧表示 | 必要 | 不要 | 自分のレビューのみ |
| 会員退会 | 必要 | 不要 | 自分のアカウントのみ |
| 管理画面ダッシュボード | 必要 | 不要 | 管理者のみ |

## MVP2の画面

### お問い合わせ画面

| 画面 | 概要 |
|---|---|
| お問い合わせフォーム画面 | ゲスト・会員が問い合わせを送信する |
| お問い合わせ送信完了画面 | 問い合わせ送信後の完了メッセージを表示する |

### 規約・ポリシー画面

| 画面 | 概要 |
|---|---|
| 利用規約画面 | 利用規約を表示する |
| プライバシーポリシー画面 | プライバシーポリシーを表示する |

会員登録画面には必要な同意・確認項目を追加する。具体的な項目と表示方法は実装Issueで決定する。

### 管理者画面

| 画面 | 概要 |
|---|---|
| 管理画面ダッシュボード | 管理者画面の基本構成と操作導線を表示する |
| 管理者作品一覧画面 | 管理者が登録済み作品を一覧で確認する。具体的な表示項目は後続設計で決定する |
| 作品登録画面 | TMDB検索結果から選択した作品を1作品ずつ登録する。入力・表示項目はTMDB技術調査後に決定する |

### 外部API連携画面

| 画面           | 概要                  |
| ------------ | ------------------- |
| TMDB検索画面     | TMDB APIから映画情報を検索する |
| TMDB検索結果画面 | 検索結果を一覧表示し、各作品の登録操作へ進む |

上記はMVP2で必要な画面の大枠である。管理画面ダッシュボードの認証・認可方式は確定しているが、未実装の管理者向け画面の構成・表示項目とTMDB API仕様は、後続の技術調査・設計で決定する。

## 補足

このドキュメントでは、画面間の流れを整理する。

具体的なURLやHTTPメソッドは `docs/ROUTES.md` に整理する。

DB設計は `docs/DATABASE.md` に整理する。

認証・認可の詳細は `docs/SECURITY.md` に整理する。
