# 機能一覧

## このドキュメントの目的

このドキュメントでは、映画レビューアプリ Laravel移植版でMVPごとに実装・整備する機能と基盤をロードマップとして整理する。

MVP2の最新スコープ・優先順位・進捗は、GitHub Milestone「MVP2 - 初回公開版（v1.0.0）」と所属Issue / Pull Requestを正本とする。この文書ではIssue番号、Open / Closed状態、完了日を逐次管理せず、機能・項目の位置付けだけを扱う。

画面遷移、ルート、DB、セキュリティ、テスト運用等の詳細は、各正本文書を参照する。

## MVP1 - 初期移植版

### アプリ機能

| 機能・項目 | 概要 |
|---|---|
| 作品一覧表示 | 登録済み作品を一覧表示し、ページネーション、平均評価、評価件数を表示する |
| 作品詳細表示 | 作品情報、レビュー、レビュー返信、平均評価、評価件数を表示する |
| 会員登録・ログイン・ログアウト | Laravel Breezeをベースに認証機能を提供する |
| パスワードリセット | Laravel Breeze標準のパスワードリセット機能を使用する |
| アカウント管理 | ユーザー名、プロフィール、パスワードを更新する |
| ユーザーアイコン | アイコンの登録・差し替え・表示と保存前プレビューを行う |
| レビュー・評価投稿 | 会員が作品にレビュー本文と評価を投稿する |
| レビュー削除 | 自分が投稿したレビューを削除する |
| レビュー返信 | レビュー返信の表示と投稿を行う |
| 本人レビュー一覧 | 自分のレビューをページ単位で表示する |
| 会員退会 | アカウントを削除し、既存のレビュー・返信は匿名表示で維持する |

### 開発基盤

| 機能・項目 | 概要 |
|---|---|
| Laravel Sail | Dockerを利用したローカル開発環境 |
| Laravel Breeze | Laravel標準に近い認証基盤 |
| MySQL | アプリケーションのデータベース |
| phpMyAdmin | ローカルでのDB確認を補助する管理ツール |
| Mailpit | ローカルでメール内容を確認する環境 |
| Git / GitHub | バージョン管理とPull Requestによる開発運用 |

### テスト・品質基盤

| 機能・項目 | 概要 |
|---|---|
| PHPUnit | LaravelのUnit / Featureテスト |
| Laravel Pint | PHPコードのフォーマット確認 |
| PHPStan / Larastan Level 4 | MVP1完了時点の静的解析基準 |
| GitHub Actions CI | PHP品質確認、Vite build、PHPUnitを自動実行する基盤 |

## MVP2 - 初回公開版（v1.0.0）

### 実装済み

#### アプリ機能

| 機能・項目 | 概要 |
|---|---|
| Laravel Breeze標準メール認証 | Laravel標準のメール認証によりメールアドレスを確認する |
| 認証メール再送 | 未認証ユーザーが認証メールを再送する |
| 管理者認証・認可 | 既存のLaravel Breeze認証を維持し、`users.role`により管理者画面へのアクセスを制御する |
| 管理画面ダッシュボード | 管理者画面の基本構成と操作導線を表示する |

#### 開発基盤

| 機能・項目 | 概要 |
|---|---|
| GitHub開発運用の整備 | `develop`を統合先とするIssue・branch・Pull Request・同期運用を整備した |
| Claude Codeの安全な調査・レビュー基盤 | 読み取り専用を原則とする権限、Hook、helper、運用文書を整備した |
| GitHub Security / Dependabot Alerts対応 | 依存関係の監視、Alertの分類、必要な更新を行った |
| PHP 8.4への更新 | 開発・CIのPHP baselineを8.4へ更新した |
| Laravel 13への更新 | Laravel 10からサポート対象版へ段階的に更新した |

#### テスト・品質基盤

| 機能・項目 | 概要 |
|---|---|
| PHPStan / Larastan Level 10 | 静的解析レベルを段階的に引き上げた |
| Playwright Test / TypeScript | 実ブラウザ上の操作を確認するE2Eテスト基盤を導入した |
| Playwright E2E専用DB / fixture | 通常開発DBと分離したE2E専用DBと合成fixtureを整備した |
| Playwright GitHub Actions統合 | Chromiumを使用するPlaywright E2EをCIへ統合した |

### 対応予定

#### アプリ機能

| 機能・項目 | 概要 |
|---|---|
| 作品詳細画面への評価分布表示 | 評価ごとの件数・割合を作品詳細画面に表示する |
| お問い合わせフォーム | ゲスト・会員が運営者へ問い合わせをメール送信する |
| 利用規約の表示 | 利用規約をアプリ上で確認できるようにする |
| プライバシーポリシーの表示 | プライバシーポリシーをアプリ上で確認できるようにする |
| 会員登録時の同意確認 | 会員登録時に必要な同意・確認を行う。具体的な確認項目は実装Issueで決定する |

#### 管理者機能

| 機能・項目 | 概要 |
|---|---|
| 登録済み作品一覧 | 管理者が登録済み作品を一覧で確認する。具体的な表示項目は後続設計で決定する |

管理者画面は一人運営に必要な最小限とし、既存のLaravel Breeze認証と `users.role` による管理者認可を使用する。登録済み作品一覧などの管理機能は段階的に対応する。

#### TMDB連携

| 機能・項目 | 概要 |
|---|---|
| TMDB利用条件・クレジット対応 | attribution、notice、approved logo、branding等を公式情報に基づいて確認・反映する |
| TMDB API技術調査・検証 | APIの取得・変換・エラー処理等を実装前に調査する |
| TMDB API連携 | 管理者機能から映画情報を取得できるようにする |
| 映画検索 | TMDBで映画を検索し、検索結果を一覧表示する |
| 1作品ずつの登録 | 検索結果の各作品に登録操作を設け、1作品ずつ登録する |
| 重複登録防止 | 同じ作品の重複登録を防ぐ。判定方式とDB制約は技術調査後に決定する |

大まかな順序は、管理者画面モック、TMDB利用条件・クレジット対応、TMDB API技術調査・検証、API連携、映画検索、1作品ずつの登録、重複登録防止とする。最小フローは「TMDB検索 → 検索結果一覧 → 各作品の登録操作 → 1作品ずつ登録」とする。

API endpoint・認証方式・timeout・retry、採用フィールド、日本語タイトル・公開日・ポスターの扱い、DB保存項目、`tmdb_id`の最終仕様、重複判定キー・DB制約は、この文書では確定しない。

#### 公開準備

| 機能・項目 | 概要 |
|---|---|
| 法令・運営上の義務の調査 | ユーザー投稿型サービスに適用される法令と運営上の義務を確認する |
| 利用規約の整備 | 公開に必要な利用規約本文を整備する |
| プライバシーポリシーの整備 | 公開に必要なプライバシーポリシー本文を整備する |
| MIT Licenseの追加 | アプリ独自コードのライセンスを明示する |
| 公開前ドキュメント整備 | READMEを含む公開向けドキュメントを整理する |
| XServer本番環境の調査・確認 | 公開方法と本番環境の条件を確認する |
| XServer本番メール設定 | パスワードリセット、メール認証、お問い合わせに必要なメール設定を整える |
| XServerデプロイ | 初回公開版をXServerへ反映する |
| v1.0.0タグ作成 | 初回公開版を示すタグを作成する |
| GitHub Release作成 | v1.0.0のReleaseを作成する |
| 公開後の動作確認・一般公開 | 本番動作を確認し、一般公開する |

大まかな順序は、法令・運営上の義務の調査、利用規約、プライバシーポリシー、MIT License、公開前ドキュメント、本番環境、本番メール、XServerデプロイ、v1.0.0タグ、GitHub Release、公開後確認、一般公開とする。規約等の表示と会員登録時の同意確認はアプリ機能、本文整備は公開準備として扱う。

## MVP2対象外の将来候補

### 会員・レビュー機能

| 機能・項目 | 概要 |
|---|---|
| レビュー編集 | 自分のレビュー本文と評価を編集する |
| レビュー返信編集 | 自分のレビュー返信を編集する |
| レビュー返信削除 | 自分のレビュー返信を削除する |
| お気に入り機能 | 作品をお気に入り登録する |
| レビュー返信への返信・多階層コメント | コメントに返信できる階層構造を追加する |
| ネタバレ表示切替 | レビューのネタバレを利用者が切り替えて表示する |
| アバター画像の自動リサイズ・最適化 | 保存画像のリサイズ、形式変換、EXIF除去等を行う |

### 管理者・作品管理

| 機能・項目 | 概要 |
|---|---|
| 作品詳細モーダル | 管理者作品一覧から作品詳細をモーダルで確認する候補 |
| 作品編集 | 登録済み作品を編集する |
| 作品削除 | 登録済み作品を削除する |
| お問い合わせ管理 | 問い合わせ内容を管理画面で確認・対応する |
| 管理者操作ログ | 管理者による操作を記録する |
| カテゴリ管理 | カテゴリの追加・編集等を行う |

### 作品探索・表示機能

| 機能・項目 | 概要 |
|---|---|
| タイトル検索 | 作品タイトルで登録済み作品を検索する |
| カテゴリ絞り込み | カテゴリを指定して作品を絞り込む |
| 並び替え | 評価、評価件数、新着等による並び替えを検討する |
| 作品ランキング表示 | 集計結果をもとに作品ランキングを表示する |
| おすすめ作品表示 | おすすめ作品を表示する。選定方式は将来検討する |

### 通知・メール

| 機能・項目 | 概要 |
|---|---|
| アプリ内通知 | アプリ内で通知を表示する |
| 退会完了メール | 会員退会後に完了メールを送信する |
| お問い合わせ受付メール | 問い合わせ送信者へ受付メールを送信する |
| その他の追加メール通知 | 新たな機能に応じて必要性を検討する |

### 運営・安全機能

| 機能・項目 | 概要 |
|---|---|
| レビュー通報 | 不適切なレビューを運営者へ報告する |
| コメント通報 | 不適切なレビュー返信を運営者へ報告する |
| ユーザーBAN / 利用停止 | 運営判断でユーザーの利用を制限する |
